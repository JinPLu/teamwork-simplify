# Evidence-dependent decisions

Read the current question and relevant project judgment when continuity matters. Compare the active options using the evidence, cost and premise that separates them; identify your own proposal as such.

For a research direction, explain the closest work, remaining gap, executable mechanism, smallest discriminating experiment, resource cost, falsification and the hard part that remains. Scale this to the actual question rather than requiring a document template or fixed sequence.

When challenged, identify the disputed premise and revise the dependent judgment. Keep unrelated choices intact. Match each important result to the object, version and conditions that support it.

Use the existing topic or plan to preserve consequential user choices, their reasons and evidence that future work cannot reconstruct. Routine execution, scheduling, approval, models and delegation use the host's native mechanisms.
